# 📊 Data Analytics Project

This project demonstrates an end-to-end **Data Analytics workflow**, starting from raw dataset loading and data cleaning to exploratory data analysis, SQL-based analysis, and dashboard creation.

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/your-repository.git
cd your-repository
```

### 2. Install Python Dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 3. Start Jupyter Notebook

```bash
jupyter notebook
```

Open the project notebook and run the cells in order.

### 4. SQL Analysis

Import the cleaned dataset into your preferred database:

* PostgreSQL
* MySQL
* SQL Server

Then execute the SQL scripts available in the `sql/` folder.

### 5. Power BI

Open the Power BI `.pbix` file and refresh the data source if required.
